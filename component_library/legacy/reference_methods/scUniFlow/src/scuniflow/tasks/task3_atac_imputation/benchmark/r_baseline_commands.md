# R Baseline Methods: Setup and Run Commands

Source directories are under `benchmark/`:

- `SAVER`: scRNA-seq denoising method, run on peaks x cells raw ATAC counts.
- `scImpute`: scRNA-seq dropout imputation method, run on peaks x cells raw ATAC counts.
- `scBFA`: binary factor analysis; output is reconstructed accessibility probability.
- `cisTopic`: scATAC topic model; output is topic-model predictive accessibility score.

## Environment

The local R environment has been created at:

```bash
${RSCRIPT:-Rscript}
```

To recreate it:

```bash
cd ${SCUNIFLOW_ROOT:-.}/src/scuniflow/tasks/task3_atac_imputation
bash benchmark/install_r_method_deps.sh
```

`SAVER` must be installed into the R environment because its internal `foreach` calls load package `SAVER` by name. The setup script installs it from `benchmark/SAVER`.

## Data Interface

All four methods use the aligned raw-count ATAC matrix generated by:

```bash
benchmark/run_benchmark_method.sh mouse_top5k prepare_raw
benchmark/run_benchmark_method.sh mouse_top50k prepare_raw
```

The wrapper exports h5ad `X` to MatrixMarket as `features x cells`, runs the R method, imports the MatrixMarket output back to h5ad, and then rank-normalizes per cell for the existing biological/masked evaluation.

## Recommended First Runs

Run top5k first. SAVER, scImpute, and scBFA are dense/heavy on top50k and are guarded unless `ALLOW_HEAVY_R=1` is set.

```bash
cd ${SCUNIFLOW_ROOT:-.}/src/scuniflow/tasks/task3_atac_imputation
mkdir -p benchmark/outputs/mouse_top5k/logs

nohup bash -c 'NCORES=8 SAVER_NPRED=0 benchmark/run_benchmark_method.sh mouse_top5k saver && benchmark/eval_method.sh mouse_top5k benchmark/outputs/mouse_top5k/mouse_top5k_saver_eval.h5ad benchmark/outputs/mouse_top5k/mouse_top5k_saver.biological_eval.json' \
  > benchmark/outputs/mouse_top5k/logs/saver_full.log 2>&1 &

nohup bash -c 'NCORES=8 SCIMPUTE_K=10 SCIMPUTE_DROP_THRE=0.5 benchmark/run_benchmark_method.sh mouse_top5k scimpute && benchmark/eval_method.sh mouse_top5k benchmark/outputs/mouse_top5k/mouse_top5k_scimpute_eval.h5ad benchmark/outputs/mouse_top5k/mouse_top5k_scimpute.biological_eval.json' \
  > benchmark/outputs/mouse_top5k/logs/scimpute_full.log 2>&1 &

nohup bash -c 'SCBFA_FACTORS=30 SCBFA_MAXIT=100 SCBFA_CHUNK_SIZE=1000 benchmark/run_benchmark_method.sh mouse_top5k scbfa && benchmark/eval_method.sh mouse_top5k benchmark/outputs/mouse_top5k/mouse_top5k_scbfa_eval.h5ad benchmark/outputs/mouse_top5k/mouse_top5k_scbfa.biological_eval.json' \
  > benchmark/outputs/mouse_top5k/logs/scbfa_full.log 2>&1 &

nohup bash -c 'CISTOPIC_TOPICS=30 CISTOPIC_ITERATIONS=500 benchmark/run_benchmark_method.sh mouse_top5k cistopic && benchmark/eval_method.sh mouse_top5k benchmark/outputs/mouse_top5k/mouse_top5k_cistopic_eval.h5ad benchmark/outputs/mouse_top5k/mouse_top5k_cistopic.biological_eval.json' \
  > benchmark/outputs/mouse_top5k/logs/cistopic_full.log 2>&1 &
```

Tail logs:

```bash
tail -f benchmark/outputs/mouse_top5k/logs/cistopic_full.log
```

## Masked Evaluation

After each method finishes:

```bash
python benchmark/eval_masked_method.py \
  --raw_atac_h5ad data/pbmc_5k_mouse_brain/e18_mouse_brain_fresh_5k_atac_tfidf_top5k.h5ad \
  --imputed_atac_h5ad benchmark/outputs/mouse_top5k/mouse_top5k_METHOD_eval.h5ad \
  --output_json benchmark/outputs/mouse_top5k/mouse_top5k_METHOD.masked_eval.json
```

Replace `METHOD` with `saver`, `scimpute`, `scbfa`, or `cistopic`.

## Top50k

cisTopic is the most reasonable top50k candidate among these four:

```bash
nohup bash -c 'CISTOPIC_TOPICS=30 CISTOPIC_ITERATIONS=500 benchmark/run_benchmark_method.sh mouse_top50k cistopic && benchmark/eval_method.sh mouse_top50k benchmark/outputs/mouse_top50k/mouse_top50k_cistopic_eval.h5ad benchmark/outputs/mouse_top50k/mouse_top50k_cistopic.biological_eval.json' \
  > benchmark/outputs/mouse_top50k/logs/cistopic_full.log 2>&1 &
```

Force dense/heavy methods on top50k only if enough memory/time is available:

```bash
ALLOW_HEAVY_R=1 NCORES=8 benchmark/run_benchmark_method.sh mouse_top50k saver
ALLOW_HEAVY_R=1 NCORES=8 benchmark/run_benchmark_method.sh mouse_top50k scimpute
ALLOW_HEAVY_R=1 SCBFA_FACTORS=30 SCBFA_MAXIT=100 benchmark/run_benchmark_method.sh mouse_top50k scbfa
```

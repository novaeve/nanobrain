## 第一层：排列的价值（验证核心假设）

| 实验条件 | 验证什么 |
|---|---|
| 随机排列，不训练 Q | 排列本身是否有价值 |
| 谱嵌入排列，冻结 Q | 数据驱动精修是否优于纯先验 |
| 谱嵌入初始化 + 训练 Q（完整方法） | 联合优化的效果 |
| 直接随机初始化 Q，不用谱嵌入 | 冷启动问题的严重程度，谱嵌入初始化是否必要 |

## 第二层：序列建模结构的价值

| 实验条件 | 验证什么 |
|---|---|
| 行内单向 Mamba（去掉反向扫描） | 双向设计的价值 |
| 去掉 ColSSM（只有行内双向） | 列间通信是否必要 |
| ColSSM 单向（只从上到下） | 列间双向 vs 单向的差距 |
| chunk_size=256 vs chunk_size=174（行对齐） | chunk 边界与矩阵结构对齐的价值 |
| 替换为 Transformer，序列截断到 2000 非零基因 | 全基因组建模 vs 只处理非零基因 |
| 替换为普通 Mamba（非层次化，直接处理 30000 序列） | 层次化设计 vs 平铺设计 |

## 第三层：输入设计的价值

| 实验条件 | 验证什么 |
|---|---|
| 去掉零值基因，只处理非零基因（序列长度约 2000） | 保留零值基因的价值 |
| K 包含表达值（违反跨细胞一致性约束） | 一致性约束的必要性 |
| 不做 log1p，直接用 raw count | log1p 归一化的必要性 |
| log1p + per-cell z-score vs 只做 log1p | z-score 归一化的边际收益 |

## 第四层：Flow Matching 设计的价值

| 实验条件 | 验证什么 |
|---|---|
| 推理时固定 context（不每步重新计算） | condition mismatch 的实际损害 |
| x_0 ~ N(0,1) vs x_0 ~ N(0.5, 0.8²) | 先验分布对齐的收益 |
| 训练和推理用不同先验分布 | 训练推理一致性的重要程度 |
| MSE loss vs Huber loss | 损失函数对偏斜分布的影响 |
| Euler 步数：1, 2, 5, 10, 20, 50 | 确认收敛所需最少步数 |
| 替换 Flow Matching 为 DDPM（扩散模型） | 生成框架本身的选择 |
| 替换 Flow Matching 为直接回归（MLP 预测均值） | Flow Matching 相比点估计的收益 |

这一层之前完全没有提到，但同样需要验证。

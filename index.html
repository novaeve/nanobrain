原理

提案、训练、复验、晋级。

nanoBrain 不是 Brain World Model 的缩小版，而是它的试验台：新架构、新目标先在可控的数据上被证实或证伪，有用的想法再搬去大规模训练。

01架构即 JSON 图

主干、速度场、任务头都是 ≤32 节点的有向无环图，节点来自已注册组件，非法连接在构建前被拒绝。

02LLM 提案

读取父架构、各任务完整指标和历史成败，提交完整图或 JSON Patch，并写明改动假设与代价。

03独立训练

每个候选为四个任务各训一份权重、三颗配对 seed；不从不同候选拼接各任务的最好分数。

04晋级门槛

综合分须比父代和参考模型都高 ≥0.002，单任务退化不超上限，每个 seed 都成功。

演化

参数量与性能。

2026-09 首轮演化的候选在 validation 上的成绩：每个点是一次单 seed、150–300 步的短训练，蓝线连接 Pareto 前沿。

不要和排行榜直接比较这些点来自 validation、短预算、单 seed，发育指标的尺度也与测试榜不同；它们说明搜索在探索什么，不说明谁更强。
V1 联合训练

最好的候选只提高 0.0008，低于 0.002 门槛，按协议保留原模型。负结果同样入账。

V2 独立训练 + 计算图

四任务分别训练；架构从固定流水线改为可插入、删除、重排节点与跳连的 JSON 图。

输入组件

Harmony、Scanorama、BBKNN 作为冻结的输入组件，CellTypist 作为线性任务头，由 LLM 组合。

上手

五分钟跑通一次实验。

Linux x86_64 · Python 3.12 · uv。20 步只验证数据加载、反传与回执写出，不是 benchmark 预算。

zsh
git clone https://github.com/novaeve/nanobrain.git && cd nanobrain
wget https://github.com/novaeve/nanobrain/releases/download/v1.0.0-data/nanobrain-v3-100k-metadata-v2.zip
unzip nanobrain-v3-100k-metadata-v2.zip -d assets/
cp .env.example .env && bash scripts/bootstrap.sh

uv run python scripts/train_nanobrain.py \
  --data assets/nanobrain_v3_100k_metadata_v2 \
  --task annotation --steps 20 --batch-size 16 \
  --device cpu --precision fp32 --output results/annotation-smoke

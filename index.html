01 · 原理

一个闭环：提案、训练、复验、晋级。

nanoBrain 不是 Brain World Model 的缩小版，而是它的试验台：新的架构、目标和采样策略先在可控的数据上被证伪或证实，有用的想法再搬到大规模训练。

  1. 1

    架构即 JSON 图

    主干、速度场、任务头都是有向无环图：≤32 节点，节点来自已注册组件（scBrain SwiGLU、scFiT attention、Harmony、BBKNN…），非法连接在构建前被拒绝。

  2. 2

    LLM 提案

    LLM 读取父架构、各任务完整指标和历史成败，提交完整图或 RFC 6902 JSON Patch，并写明改动假设与预期代价。

  3. 3

    四任务独立训练

    每个候选为四个任务各训练一份权重，三颗配对 seed；非当前任务参数冻结，不从不同候选拼接分数。

  4. 4

    晋级门槛

    综合分须比父代与参考模型都提高 ≥0.002，且单任务退化不超上限、每个 seed 都成功。失败方案保留记录，不传播。

02 · 任务

四个问题，覆盖虚拟细胞的核心能力。

细胞注释

从表达向量识别细胞类型。类别极不均衡，主指标用 Macro F1，稀有类型与常见类型等权。

主指标
Macro F1 ↑

数据整合

去除批次差异，同时保留生物信号。只做批次对抗会丢信息，因此整合目标内置表达重建。

主指标
Integration composite ↑

发育预测

给定来源群体和年龄间隔，预测目标时间点的细胞群体分布（非配对横截面数据）。

主指标
Population MSE ↓

空间生态位

理解细胞所处的空间邻域。当前榜单沿用旧协议，以解剖区域标签作代理衡量聚类一致性；V3 已改为邻域组成预测。

主指标
ARI ↑

04 · 演化

参数量与性能：历史演化候选。

2026-09 首轮架构演化的候选在 validation 上的成绩，每个点是一个单 seed、150–300 步的短预算训练。横轴为训练回执记录的参数量（对数），线连接 Pareto 前沿。

不要和排行榜直接比较这些点来自 validation、短预算、单 seed，且发育指标的尺度与测试榜不同；它们说明搜索在探索什么，而不是谁更强。
V1 联合训练

1 代、4 个真实 LLM 提案；最好的候选提升 0.0008，低于 0.002 门槛，按协议保留原模型。负结果同样被记录。

V2 任务独立 + 计算图

四任务分别训练；架构从固定流水线改为 JSON 计算图，可插入、删除、重排节点与跳连。

输入组件扩展

Harmony / Scanorama / BBKNN 作为冻结的数据集级输入组件，CellTypist 作为线性任务头，可被 LLM 组合。

05 · 进展

项目时间线

  1. 2026-11-03
    V3 指标下的 50 代演化启动

    每代 6 个候选 × 3 seed × 4 任务、每次 10,000 步；测试成绩参与架构选择（探索性搜索，非 holdout 结果）。运行中，结果未发布。

  2. 2026-11-02
    四任务指标协议 V3

    空间任务改为 Nicheformer 式邻域组成预测（MAE），发育改用 W₂ 距离，整合报告 scIB 单项。

  3. 2026-10-27
    Graph V2 成为标准演化协议

    合入 main；官网与排行榜服务上线，结果回执可自动提交。

  4. 2026-10-23
    输入组件扩展

    新增 CellTypist、Harmony、Scanorama、BBKNN 组件；全部测试 244 项通过。

  5. 2026-09-20
    可组合架构 API V2

    JSON 计算图、独立目标注册接口、JSON Patch 提案。

  6. 2026-09-17
    首轮 LLM 演化

    改进未过门槛，保留参考模型；随后改为任务独立训练流程。

  7. 2026-09-16
    冻结测试评估

    nanoBrain FMT 3 seeds × 2,000 步与 28 个对照方法完成测试集评估，错误行 0。

06 · 上手

五分钟跑通一次实验。

Linux x86_64 · Python 3.12 · uv。20 步只验证数据加载、反传和回执写出，不是 benchmark 预算。

  • 中文 README
  • 计算图 API
  • 完整排行榜与 CSV
  • 接入自己的模型
git clone https://github.com/novaeve/nanobrain.git && cd nanobrain
wget https://github.com/novaeve/nanobrain/releases/download/v1.0.0-data/nanobrain-v3-100k-metadata-v2.zip
unzip nanobrain-v3-100k-metadata-v2.zip -d assets/
cp .env.example .env && bash scripts/bootstrap.sh

uv run python scripts/train_nanobrain.py \
  --data assets/nanobrain_v3_100k_metadata_v2 \
  --task annotation --steps 20 --batch-size 16 \
  --device cpu --precision fp32 --output results/annotation-smoke

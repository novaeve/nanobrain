# Frozen 100k Dataset Destination

The approved bundle is installed at this relative directory by `uv run nanobrain-data prepare`.
The company supplies `NANOBRAIN_DATA_URL`; the dataset arrays are not tracked by Git.

The bundle contains `manifest.json` and `train/`, `validation/`, and `test/` directories with the fixed 60k/20k/20k partition. See [the data contract](../../DATASET_LOCATION.md).

# nanoBrain website

A static page (`index.html`, `styles.css`, `assets/logo.png`) published with GitHub Pages from the
`gh-pages` branch: https://novaeve.github.io/nanobrain/

To update it, edit the files here, commit to `main`, then commit the same files (without this README) to
`gh-pages`. The page explains what nanoBrain is; the full manual is [docs/whitepaper_zh-CN.md](../docs/whitepaper_zh-CN.md).

The v1 site (leaderboard, frontier charts, receipt submission service) is preserved at tag `nanobrain-v1-final`.

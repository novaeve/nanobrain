03 / Learn nanoBrain

从一张细胞表达矩阵，
走到一个新架构。

教程把单细胞组学、四个任务和演化机制放到同一条可操作的路径上，适合第一次接触 virtual-cell experiments 的研究者。

01

单细胞组学
是什么？

每个细胞可以表示成一个基因表达向量。我们从 gene、cell type、tissue 和 batch 开始，理解为什么表达矩阵稀疏、噪声大，还会受到批次效应影响。

阅读基础 →
02

四个任务，
四个问题。

Annotation 识别细胞类型；Integration 保留生物信号并减少 batch signal；Development 预测群体变化；Spatial niche 理解空间邻域。

查看任务 →
03

演化算法，
怎样找到架构？

Genome 描述候选架构，mutation 产生新候选，训练和验证给出四任务指标，joint score 与 improvement gate 决定哪些候选进入下一代。
